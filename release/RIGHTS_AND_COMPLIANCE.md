# 权利与合规闸门

## 暂不可公开分发的内容

- 根目录小说全文 `《我在废土世界扫垃圾》完结+全番外.txt`；
- `analysis/`、`data/processed/` 等由原文生成的研究语料；
- 未经单独确认授权的原作角色、剧情、对白、封面或插图；
- 本地 API Key、Vault、存档、日志、测试 trace 和浏览器会话；
- 上游项目的整个源码或示例资产（除非逐项满足其许可证与署名要求）。

## 公开前必须由权利人/项目负责人确认

1. 是否已获得小说的游戏改编权、信息网络传播权和商业发行权，以及授权地区、平台、期限和语言。
2. 若没有授权，是否改为完全原创的世界、人物、地名、剧情事实和宣传名称。
3. 项目代码的版权主体和最终许可证文本。
4. 所有 PNG/SVG、字体、音乐、音效和商店宣传素材的作者、生成方式、许可与可商用范围。
5. 使用 DeepSeek 或其他模型服务时的用户协议、隐私政策、数据流、日志保留和未成年人政策。

## Steam AI 披露摘要草案

本游戏可在运行时使用生成式 AI，为玩家自由行动生成受控的叙事段落。模型只能在当前可见事实、登记地图连接、角色权限和有效选项范围内提出事件；运行时会再次验证行动主体、状态变化、背包、隐藏事实和不可逆规则，不合法提案会被拒绝并降级为本地确定性流程。正式提交前仍需增加违法/侵权内容防护与玩家举报入口，并让此描述与实际使用的模型服务完全一致。

本文件不是法律意见；涉及原作改编和商业发行时，应取得书面授权并由熟悉目标发行地区的专业人士复核。
