# 头盔第一视角 HUD 资源依据

资源：`ui/helmet-hud-source.png`  
用途：右侧栏的第一视角头盔面板底图；污染、通讯、氧气、防护、温度和行动窗口由运行时 HTML 层实时覆盖。

## 原文依据

原始小说摘录位于 `data/raw/《我在废土世界扫垃圾》完结+全番外.txt`，本资源只抽取装备与读数相关事实：

- 第 202–205 行：清理服接近摩托车服，纯黑、皮革质感；纯黑头盔；胸口按钮使服装膨胀、抗冲击并供氧，不能露出皮肤。
- 第 227、405–414 行：头盔共享公共语音频道，并带摄像头，可向总部回传画面。
- 第 254–263、801–802 行：头盔具备夜视与自动锁定污染实体；过滤器阻断气味；夜视需要时间调焦，视野可能塌缩。
- 第 533–546 行：头盔可检测污染浓度；污染区会干扰通讯，猎人频道相对稳定。
- 第 590–598 行：头盔是黑色全包裹式，进入污染区后内部时钟会冻结。
- 第 711–713、1048–1050 行：支持音频记录、视频记录和基础数据检测，即使无网络仍可工作。
- 第 812–814、984–990 行：撕裂或摘下头盔会增加感染/窒息风险；李念川不适时表现得像一条小狗，不能随意摘下。

## 视觉与交互映射

1. 图片采用佩戴者视角：面罩边框包住画面，中央是潮湿轨道与隧道，表达“先通过头盔观察”。
2. 图片不写入文字和数字，避免生成图污染事实；读数由 `preview.html` 的 `helmet-data-overlay` 和 `helmet-grid` 按运行时状态绘制。
3. 夜视调焦、通讯干扰、过滤器和摄像头以画面边缘的设备轮廓表达；实际数值仍以 `helmetReadout` 为准。
4. 头盔读数只读公开状态，DeepSeek 可以导演事件和可见分支，但不能直接改写隐藏数值。
